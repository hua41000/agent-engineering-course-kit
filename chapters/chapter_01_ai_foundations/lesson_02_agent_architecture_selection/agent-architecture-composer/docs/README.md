# 方案文档

本目录保存 Agent Architecture Composer 的产品需求、方法设计、技术方案与交付管理提案。文档和首版实现均为 `review`。当前已提供离线 Web 和 Skill；各设计文档开头注明简化后的实施范围。

- [产品需求](prd.md)：定义要解决的问题、两端体验和验收条件。
- [方法设计](methodology.md)：把课程方法转成可解释、可测试的决策规则。
- [技术方案](technical-design.md)：定义共享内核、数据与工程边界。
- [交付管理](delivery-management.md)：定义资产归属、变更与发布方式。
- [可靠性评审](reliability-review.md)：记录设计缺口、情景推演、修订优先级与关闭条件。

项目状态与来源统一回到 [项目入口](../README.md)；每个议题只有上述一个负责文档，不另建同义方案或多个版本副本。

## 主题接入与唯一来源

`src/index.html` 在根元素声明 `data-bxy-profile="adaptive"` 与 `data-bxy-theme="light"`。

`design-system/bxy-design-tokens.json` 保存设计值，`bxy-design-tokens.css` 为基础 Web 映射。`scripts/build.mjs` 读取基础 CSS，并从 JSON 的 `project`、`projectMobile` 生成项目覆盖，再拼接图标字体、`src/styles.css` 与 `src/presentation.css`，注入独立 HTML。项目组件引用语义变量，修改项目值只改 JSON；更新基础值时同步维护 CSS 映射。禁止直接修改 `work/` 产物。

| 语义 | 实际接入 | 用途 |
|---|---|---|
| 品牌主色 | `--bxy-color-brand` | 主按钮、真实答题进度 |
| 选中/焦点 | `--bxy-color-brand-text`、`--bxy-color-focus` | 单选、章节选中、键盘焦点 |
| 正文/说明 | `--bxy-color-text`、`--bxy-color-text-secondary` | 系统中文无衬线字体 |
| 页面/面板 | `--bxy-color-page`、`--bxy-color-card` | 浅灰底、白色内容区 |
| 表单边界 | `--bxy-color-control-border` | 输入、选项与按钮边界 |
| 圆角 | `--bxy-radius-md`、`--bxy-radius-panel` | 8 px 控件、12 px 面板 |
| 正文 | `--bxy-text-body`、`--bxy-line-body` | 桌面 14/22，手机 13/22 |
| 操作高度 | `--bxy-control-height`、`--bxy-control-touch` | 桌面 36 px，手机至少 44 px |
| 弹层 | `--bxy-shadow-modal`、`--bxy-color-mask` | 原生 dialog 与遮罩 |
| 图标 | `.bxy-icon`、`assets/icons/icon-map.json` | Material Symbols Rounded，14 个功能图标 |

组件入口为 `src/app.js`。单选使用原生 radio，多选使用原生 checkbox；每题有题目分组和可访问名称，章节导航有当前项语义，必填错误关联输入，导入错误持续显示，导入中禁用重复入口，完成后显示状态消息。弹层支持 Escape、焦点返回和点击遮罩关闭。手机更多操作收进底部弹层。

## 项目例外与边界

| 项目 | 实施与理由 | 维护方式 |
|---|---|---|
| 离线图标 | 使用自托管字体子集，构建为 data URL；字体 1,840 字节，无 CDN 请求 | 增加图标时更新子集和映射；来源、哈希、轴值见 manifest 与 icons/README |
| 品牌按钮文字 | 主色保持橙色，文字使用 `#262626`，实测对比度 5.77:1；悬停 5.10:1 | 保持普通文字至少 4.5:1 |
| 可读性覆盖 | 深橙选中文字、焦点；更深的红/绿反馈与控件边界 | 选中文字 5.94:1，错误文字 6.02:1，成功文字 6.01:1，控件边界/白底 3.59:1 |
| 手机说明/输入 | 说明文字保持 12/18；输入使用 16 px，以便阅读和触摸输入 | 在实际手机浏览器继续校准 |
| 标题行高 | 24 px 标题配 32 px 行高，容纳长中文和中英混排 | 不限制项目标题为单行 |
| 布局几何 | 767 px 移动断点、1100 px 侧栏折叠断点、1600 px 总宽上限、180 px 流程节点最小宽、480 px 代码块滚动上限、400 px 桌面工具弹层宽 | 这些是内容布局约束，保留于组件 CSS；其余视觉值使用 tokens |
| 动效 | 首页使用入场与 SVG 路径流动；问卷保持短过渡；报告结构图静态 | 支持暂停、离屏暂停、隐藏标签暂停及 reduced motion；无图标形变 |
| 平台与图表 | 无 App 外壳、无统计图表；实际阶段使用语义 HTML，控制结构主视觉使用原创 SVG | 图形有文字标签及可访问名称；图内坐标/字号按固定 viewBox 缩放 |
| 主题 | 产品当前只开放浅色；基础包含暗色变量，未开放或验收暗色 | 开放暗色前补充项目覆盖与检查 |

以上为本次独立工具的实施决策，维护负责人为 `guomeiqing`；原离线交付要求和可读性要求继续有效时保留。图标授权为 Apache-2.0，完整许可随源码、独立 HTML 注释和构建目录交付。

## 品牌、首页与报告补充（2026-09-22）

用户明确要求 Logo、酷炫首页及带设计和装饰的报告。保留 `adaptive` 基础，在 `presentation.css` 中限定首页与报告的视觉扩展：暖纸底、深色架构画布、橙色主动作、鼠尾草绿 Skill 区、较大标题、封面橙色顶线与低透明度 Logo 水印。正文仍有明确层级和足够对比度。布局几何、SVG 坐标与字号、动画位移/透明度保留在组件中，颜色、主字号、间距、时长和阴影使用项目 tokens。

首页展示三种控制方式的可切换结构示意；提供开始/继续评估、典型案例、完整示例报告与 Skill 下载入口。模式切换只影响展示；示例在独立的内存状态中生成，不改写正在填写的 Session。报告封面展示真实项目条件和填写数量，推荐结构后按理由、能力、控制权、模式、框架、实施顺序排列，未知条件继续明确提示。Markdown/JSON/ADR/Mermaid 导出共用当前展示的决策对象。

动效机制参考 [ReactBits AnimatedContent](https://github.com/DavidHDev/react-bits/blob/main/src/content/Animations/AnimatedContent/AnimatedContent.jsx) 的位移与透明度入场（访问 2026-09-22），用本项目原创 CSS 实现；路径流动与 SVG 为原创，不复制或分发组件源码，不引入 React/GSAP 依赖。已检查 OriginKit 入口，但文档未能读取，未采用其组件或资源。首屏入场 900 ms，路径周期 9 s；可手动暂停，IntersectionObserver 管理离屏，visibilitychange 管理隐藏标签；reduced motion 下移除入场和循环动画。报告不持续播放动画。

检查覆盖桌面与手机首页、报告封面/章节、多模式切换、暂停、系统减少动效模拟，以及示例返回后问卷名称、目标和已选答案的保留。此项检查不代替实际手机及完整读屏验收。

本轮浏览器检查尺寸：1440×1000 首页，1280×900 报告，390×844 首页/问卷/报告，375×812 首页底部与报告章节；无页面横向溢出。三种结构切换、手动暂停、离屏暂停、减少动态效果模拟均通过；控制台未发现警告或错误。产品 16 项回归、仓库测试、构建与语法检查通过。

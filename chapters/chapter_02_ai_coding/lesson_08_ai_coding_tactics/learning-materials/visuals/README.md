# 首页主题配图

[topic-illustrations.png](topic-illustrations.png) 是 [HTML 首页](../index.html) 六张主题卡片使用的黑白橙手绘示意图，由 [orange-sketch-diagram](https://github.com/shanggqm/geektime-course/blob/42b0e2622749350110d67bcceccb1e081c2a0ca8/.agents/skills/orange-sketch-diagram/SKILL.md) 调用内置 image_gen 生成，生成日期为 2026-10-15。

图片为 1536 × 1024 像素，按三列两行排列，每格 512 × 512 像素。首页通过 CSS 背景定位分别展示六幅图，无需额外裁切副本。

| 位置 | 主题 | 示意内容 |
|---|---|---|
| 左上 | Prompt | 任务表达与验收清单 |
| 中上 | 上下文工程 | 规则、代码、状态汇入资料夹 |
| 右上 | 任务拆解 | 拆分任务与依赖汇总 |
| 左下 | Loop Engineering | 实现、验证与反馈闭环 |
| 中下 | Hook 与 Skill | 事件触发、可复用工具与自动检查 |
| 右下 | 多 Agent 编排 | 委派、独立工作边界与结果验收 |

配图用于辅助识别主题，正文与链接仍由首页 HTML 承载；装饰图对辅助技术隐藏。

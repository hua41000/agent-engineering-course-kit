# 调研 Prompt

调研主题：【填写主题】
输出目录：【填写目录】

## 1. 做深度调研

围绕主题，从播客、博客、互联网、行业权威专家的一线真实分享、PPT 中找到核心技巧。结论要来自真实实践，避免拼接推理出看似 MECE 的结论。将研究结论及来源链接保存到输出目录的 `research.md`。

## 2. 按格式输出

基于研究结论，将最佳实践整理到输出目录的 `best_practices.md`，格式如下：

最佳实践 A：

- 标题：
- 描述：
- GoodCase：
- BadCase：

最佳实践 B：

- 标题：
- 描述：
- GoodCase：
- BadCase：

其余最佳实践按同一格式继续。
